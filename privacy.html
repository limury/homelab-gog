Privacy policy

homelab-gog is a private, single-user tool used only by its owner, with the owner's own Google accounts.

What it accesses

With the owner's consent it accesses the owner's Gmail, Google Calendar, Google Drive, Google Docs and Google Sheets data, to let the owner's own assistant read and manage it on the owner's behalf.

Where data goes

Access tokens and any data retrieved are stored and processed only on a server operated by the owner. Data is not sold, not shared with third parties, and not used for advertising. It is passed to the AI assistant the owner chooses to use, at the owner's request.

Retention and removal

Data is kept only as long as the owner keeps it on their server. Access can be revoked at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
